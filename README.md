# cafe-app

A modern cafe app built as a responsive single-page storefront with:
- hero section and brand identity
- menu filtering by category
- dynamic interactive add-to-cart behavior
- order summary sidebar and totals
- mobile-friendly layout

## Run locally

Open `index.html` directly in a browser, or serve the folder with any simple static file server.

Example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
